# Third-party assets

Every third-party asset in this repository is listed here with its source and license. Code libraries are listed in each `package.json`; this file covers fonts, 3D models, textures, scans and any other media.

Everything not listed here (objects, effects, lighting, sounds, UI art) is made in code by this project and is covered by the repository's MIT license.

## Fonts

Fonts are bundled from npm at build time and served from our own host. No font CDN is used at runtime.

| Asset | Use | Package and version | Source | License |
| --- | --- | --- | --- | --- |
| Fraunces (variable) | Display serif: headings, product names, price tags | `@fontsource-variable/fraunces` 5.3.0 | Undercase Type, https://github.com/undercasetype/Fraunces | SIL Open Font License 1.1 |
| Inter (variable) | UI sans: navigation, body copy, controls | `@fontsource-variable/inter` 5.3.0 | Rasmus Andersson, https://github.com/rsms/inter | SIL Open Font License 1.1 |

Fraunces was chosen because its variable "wonk" and "soft" axes let the Haunted state drift letterforms (Requirement 40) without a second font.
